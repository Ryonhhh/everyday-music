# 阅读页设计卡（课程正文 / 专辑解析）

按 ui-taste-skill 的局部精修路径。保留已成立的身份（Instrument Serif + 无衬线正文、白底、琥珀色唯一强调、无阴影无渐变），只修「长文阅读」这一层关系。

## 任务与边界

- 对象：`detail.html` 的两种内容页——课程正文（乐理 + 音乐史，每篇 2500–5000 字）与专辑解析（7 节，含引语与曲目单）。
- 必要能力：场景是「一个人，坐下来读 15 分钟，并想核对出处」。不可改变：数据来源、路由、进度逻辑、配色与字体族。
- 本次不做：首页、课程目录、资料库。

## 审美主张

把一节课做成一页**有节制的学术读本**：书眉交代场次与时长，标题用衬线体立起版心，正文收窄到一口气读得完的行长；章节像书页一样在版心内起承；「出处」降级为贴边的细注，不打断阅读。

## 主角与陪衬

- 第一落点：标题（衬线，40px）与紧随其后的第一段。
- 第二落点：`##` 章节标题（衬线 30px，上方一条 1px 细线，标示换章）。
- 安静处：出处引注、元信息——必须退到背景，不参与视觉竞争。

## 材料与语法

| 角色 | 取舍 |
| --- | --- |
| 书眉 kicker | 11px、字距 0.14em、弱色；「课程日 07 · 约 14 分钟」/「专辑解析」 |
| 标题 | Instrument Serif，40px / 1.15；窄屏 28px |
| 副题 byline | 15px 弱色一行：课程的「并读 · 音乐史单元」，专辑的「The The · 1983」 |
| 元信息 facts | 专辑恢复五格（艺人/发行/厂牌/风格/制作），11px 标签 + 14px 值，两列网格 |
| 正文 | 17px / 1.9，行长 34em（≈36 个汉字），段距 1.15em |
| 章节 | `##` 衬线 30px，上留 2.4em + 1px 细线；`###` 18px 600，上留 1.8em |
| 引语 | 2px 左线 + 15px 弱色；`出处` 类进一步降到 13px、细线 1px、字距微增 |
| 列表 | 左缩进 1.4em，序号用表格数字、弱色 |
| 收尾 | 课程底部加上一课/下一课 |

## 实现初值

- 版心 `max-width: 720px`；视口 1440 / 1024 / 390。
- 窄屏（≤640）：标题 28px、正文 16px/1.85、facts 两列、行长自适应。

## 审美验收

1. 一行 36 字上下，读 3 段不累；
2. 标题、章节、正文三级的层级一眼可分，不靠字号以外的手段；
3. 出处能在扫读时被忽略、需要时能找到；
4. 专辑页第一屏就能读到「谁、哪年、什么风格」；
5. 手机上一个拇指宽度读完，无横向溢出。
